# 📊 SAP Consulting & Mentoring — Lucas Lins

## 📋 Overview

A high-performance, modern Single Page Application (SPA) developed as a professional portfolio and service showcase for Lucas Lins, a Senior SAP MM Consultant and Mentor.

The platform is designed to highlight his expertise in SAP S/4HANA, project implementation history, and offer specialized consulting and mentoring services. It features a clean UI, an interactive professional timeline, and a fully functional contact system.

## 🔗 Live Preview

[Portfolio Lucas Lins](https://lucas-lins.com/)

## ✨ Key Features

* 💼 **Service Showcase:** Detailed sections for SAP Mentorship, BTP Consulting, Clean Core Architecture, and Process Optimization.
* ⏳ **Interactive Timeline:** A visual journey of the consultant's career, from operational logistics to Senior SAP Greenfield implementations.
* ✉️ **Functional Contact Form:** Direct communication channel powered by Resend for reliable email delivery.
* ⚡ **Edge Optimized:** Pre-configured for Edge deployment using Cloudflare Pages via @opennextjs/cloudflare.
* 📱 **Fully Responsive:** Pixel-perfect adaptation across mobile, tablet, and desktop devices.

## 🧩 Technologies Used

This project leverages a cutting-edge React ecosystem:

* **Framework:** Next.js 16 (React 19)

* **Styling:** Tailwind CSS v4

## 📁 Architecture & Structure

The application follows a clean component-based architecture within a unified page structure:

```
sap-consulting-portfolio/
├── src/
│   ├── components/
│   │   ├── Header.tsx         # Navigation and branding
│   │   ├── Hero.tsx           # Main intro banner
│   │   ├── Services.tsx       # SAP Services (S/4HANA, BTP, etc.)
│   │   ├── About.tsx          # Professional summary & skills

│   │   └── Footer.tsx         # Bottom links & credits

├── package.json
└── cloudflare-env.d.ts        # CF types auto-generated by Wrangler
```

## 🚀 How to Run Locally

### Prerequisites

* Node.js (v20+ recommended)
* npm, pnpm, or yarn
* A Resend API Key for the contact form to work

### Installation

1. Clone the repository:

```bash
git clone https://github.com/LucasLins-S/Consultoria-e-mentoria-SAP
```

2. Navigate to the project directory:

```bash
cd sap-consulting-portfolio
```

3. Install the dependencies:

```bash
npm install
```

4. Set up your environment variables:

Create a `.env.local` file in the root directory and add your Resend API Key:

```
RESEND_API_KEY=your_resend_api_key_here
```

5. Start the development server:

```bash
npm run dev
```

6. Open your browser and access:

```
http://localhost:3000
```

## ☁️ Cloudflare Deployment

This project is highly customized to run on Cloudflare's Edge network using OpenNext.

To build the project for Cloudflare:

```bash
npm run build:cloudflare
```

To deploy directly to Cloudflare Pages (requires Wrangler authentication):

```bash
npm run deploy
```

Generate Cloudflare environment types (if you add new CF bindings):

```bash
npm run cf-typegen
```
